# AuditLens

AuditLens is a learning and research project exploring explainable anomaly detection for general ledger journal entries. It combines accounting rules with machine-learning methods to identify unusual entries and provide understandable reasons for review.

The project begins with reproducible synthetic ledger data and is being developed in stages to include planted anomalies, feature engineering, model comparisons, and evaluation. The current data is synthetic; results should not be interpreted as evidence of real-world fraud detection performance.
